# Dealer Trainer

Браузерный тренажёр для начинающих покерных дилеров.

## Запуск локально
Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Публикация через GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `dealer-trainer`.
2. Загрузите в корень репозитория файл `index.html`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Подождите завершения публикации. Адрес сайта будет иметь вид:
   `https://ВАШ-ЛОГИН.github.io/dealer-trainer/`

## Открытие на телефоне
Откройте опубликованную ссылку в браузере телефона. При желании добавьте страницу на главный экран через меню браузера.

## Что внутри
- Тренировка выбора лучшей пятикарточной комбинации в Texas Hold'em и сравнение с соперником.
- Упражнение на основной и побочный банк при трёх олл-инах.
- Тренировка набора сдачи фишками.
- Короткий тест по процедурам раздачи.
- Адаптивная вёрстка для небольших экранов.

## Важно
Это учебный прототип. Перед использованием на реальном турнире правила и расчёты следует сверять с регламентом площадки.
